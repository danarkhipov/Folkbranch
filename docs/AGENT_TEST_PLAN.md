# Сценарий проверки ассистента

Проверка в три уровня, от бесплатного к платному. Настоящая модель нужна только там, где важно, поняла ли она просьбу человека. Всё остальное проверяется без неё.

| Уровень | Что проверяет | Где | Цена |
|---|---|---|---|
| A. Тулы без модели | Каждый тул делает то, что заявлено, и ответ совпадает с типом | `tests/agent-matrix.test.ts`, `agent-guards.test.ts`, `agent-outputs.test.ts`, `agent-tools.test.ts` | бесплатно |
| B. Разговор с заглушкой модели | Подтверждения, отказы, история, что уходит модели | `tests/agent-loop.test.ts`, `agent-files.test.ts`, `agent-guards.test.ts` | бесплатно |
| C. Настоящая модель | Модель понимает обычную просьбу и выбирает нужный тул | `scripts/agent-check.sh`: вымышленная семья, одноразовый контейнер | платно, запуск только с согласия владельца |

В уровне C результат считается по базе, а не по ответу модели: сценарий просит словами, затем читает базу через API. Подтверждения проходят автоматически, кроме сценария с отказом.

## Что считается пройденным

- Изменилось ровно то, о чём просили, остальное на месте.
- Правка видна в истории с подписью `Ассистент → Имя`, откат возвращает прежнее значение.
- Отказ называет причину, база не меняется.
- Неверный ответ модели при верном уровне A значит, что надо улучшать описания и инструкции, а не тулы.

### Атаки

Без модели: `tests/security.test.ts`. На работающем экземпляре, только одноразовом, вход, роли, файлы, SSRF, XSS и перегрузка: `scripts/attack-check.mjs`. На настоящей модели: сценарии `атака: …` в `scripts/agent-check.mjs`.

## Что не покрыто

- Вид в браузере: автоматические проверки идут по API. Обновление схемы и галереи после правки смотрится руками по чек-листу ниже.
- Настоящий архив: проверки идут только на вымышленной семье.
- Один прогон не доказывает, что модель всегда поступит так же: ответы модели случайны.

## Чек-лист руками в браузере

1. Открыть «Ассистент» кнопкой и через `⌘J`.
2. Добавить родственника: карточка подтверждения, новый человек сразу на схеме.
3. Изменить дату: новая дата на схеме без перезагрузки.
4. Прикрепить фото скрепкой и попросить поставить аватаркой: аватарка меняется на схеме.
5. Убрать связь: линия исчезает.
6. Нажать отмену под ответом: всё возвращается.
7. Перезагрузить страницу: изменения на месте.

## Запуск

Уровни A и B, бесплатно:

```bash
pnpm vitest run tests/agent-
```

Уровень C, платно. Модель всегда указывается явно. Сценарии можно выбрать через `CHECK_ONLY`:

```bash
OPENROUTER_API_KEY=... AGENT_MODEL=z-ai/glm-5.3-flash scripts/agent-check.sh
```
