# Решения

## Принято

- Своё приложение, а не Gramps Web: нужен вид как Notion и Miro.
- Хостинг Railway; open source, разворачивается в пару кликов.
- SQLite и файлы на том же диске вместо Postgres и бакета: максимально просто и дёшево.
- Страницы под каждого человека с фото в тексте.
- Фото привязывается к нескольким людям, с отметкой на снимке и переходом к человеку.
- Нейросеть подключается через MCP и API, может менять всё. Текстовый графовый формат превращается в карточки.
- Вход только для приглашённых.

## Предложено, можно уточнить

- Стек из [ARCHITECTURE.md](ARCHITECTURE.md).
- Правки ИИ через очередь на проверку.
- Состав первой версии из [PRODUCT.md](PRODUCT.md).
- Сайт становится главным источником данных после импорта, без двусторонней синхронизации с каноном исследования.

## Решено 04.11.2026

- Лицензия AGPL-3.0.
- Строим с нуля; TreeTree только как образец для MCP и очереди правок ИИ.

## Правила работы

- Git только локально. Публикация на GitHub и создание шаблона Railway — только с подтверждения.
- Семейные данные и фото никуда не выгружать без явного согласия. В репозитории только вымышленная демо-семья.
- Настоящие данные импортируются только в свой экземпляр и в репозиторий не попадают.
