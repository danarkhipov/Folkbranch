Install guide

How to install Folkbranch

Folkbranch is free, self-hosted family tree software. On a Mac or Linux computer it is one command; on a server it sets up HTTPS by itself; on Windows Docker is the proven way; and your own AI can do all of it for you. Pick one way below.

Before you start

One person in the family keeps the archive and installs it. Relatives only open a link in a browser. Pick one way below; if you are not sure, take the first, since it also loads an invented demo family you can look at.

Mac or Linux: one command

curl -fsSL https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.sh | sh

No Docker and no Node needed: the command brings its own, checked against Node’s published checksums. It prints a link; open it, name your family, and load the invented demo family if you want to look around first. Want to read the script before running it? install.sh is short, and the releases hold the archives and their checksums.

  • Everything goes to ~/folkbranch (--dir for another folder): the app, your archive in data, settings in .env and the log.
  • Add --port 8080 for another port: ... | sh -s -- --port 8080. The app listens on this computer only.
  • Without Docker it does not start when the computer does. After a reboot, run cd ~/folkbranch && ./folkbranch open.
  • With Node at hand, npx folkbranch runs the same installer; run it again to open the app.
  • To remove it, run ./folkbranch stop and delete the folder. That deletes the archive too, so download a copy first.

Windows: Docker

Docker Desktop is the proven way on Windows. The repository’s docker-compose.yml runs the published image with a volume at /data:

  1. Install Docker with the Compose plugin.
  2. Copy docker-compose.yml and .env.example from the repository, then copy .env.example to .env.
  3. In .env set BETTER_AUTH_URL to the address people open and BETTER_AUTH_SECRET to a long random value.
  4. Run docker compose up -d.
  5. Open the app and use the claim link from docker compose logs folkbranch.

The volume folkbranch-data holds the archive: docker compose down keeps it, docker compose down -v deletes it. There is also a PowerShell installer, irm https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.ps1 | iex, but it has not been tried on a real Windows computer yet. Or ask your AI to set Docker up for you.

A server with your own domain

Any Linux server with systemd and 512 MB of memory: Ubuntu 22.04 or newer, Debian 12 or newer, AlmaLinux, Rocky or Red Hat 9, Fedora, or Amazon Linux 2023. No Docker and no domain are needed:

curl -fsSL https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.sh | sudo sh -s -- --server

It prints a link to name your family, for example https://203.0.113.5/setup?code=.... Open ports 80 and 443 in your hosting panel if it has its own firewall. The app and Caddy each run as a service that starts with the server, and HTTPS sets itself up with a certificate from Let’s Encrypt that renews by itself.

Your own domain. Point its DNS at the server, then run the same command with --domain family.example.com, now or later. The archive stays, but links made earlier stop working when the address changes.

Already have nginx or another web server? Add --no-caddy with your domain and proxy that domain to 127.0.0.1:3000. On a server that already has Docker, --domain family.example.com without --server runs the image with Caddy next to it.

Railway

The repository is ready for Railway: one service with a volume at /data and a health check. The Hobby plan starts at about $5 a month; check Railway’s price page. You need the Railway CLI.

railway login
railway init --name folkbranch
railway config apply
railway variable set --service folkbranch "BETTER_AUTH_SECRET=$(openssl rand -hex 32)"
railway domain --service folkbranch
railway up --service folkbranch
railway logs --service folkbranch

The logs print the link that claims the empty archive. The volume at /data is mandatory: without it the app refuses to start rather than lose your data. Run one replica only, because SQLite and the photos live on that one volume. Render, Fly.io, a VPS with Docker Compose and panels such as Coolify have a page each in the deploying guide.

Let your AI install it

Paste this line into Claude Code, Codex or Cursor:

Install Folkbranch for me by following https://github.com/danarkhipov/folkbranch/blob/main/skills/folkbranch/SKILL.md

It reads the open install guide, asks whether to install on this computer or on a server, installs, opens the archive and connects itself. It stops before anything that needs your password or money. In Claude Code you can also add the plugin with /plugin marketplace add danarkhipov/folkbranch and /plugin install folkbranch@folkbranch, then ask “Install Folkbranch”.

Backups and updates

  • Daily copy. The server copies the database by itself each day, and before each update that changes it. Those copies are on the same disk.
  • A copy you keep elsewhere. Download a full copy under Settings → Data and backups, or run ./folkbranch backup and move the file off the machine. With Docker Compose: docker compose exec folkbranch node folkbranch.mjs backup, then docker compose cp folkbranch:/data/backups ./backups.
  • Updating. Run the install command again, in any kind of install; with Docker Compose, docker compose pull && docker compose up -d. Settings and data are kept. When a release is out the owner sees a notice, and on a plain install on your own computer an Update now button that saves a checked copy of the database first.

The full details are in the self-hosting guide. Coming from another program? Read how to import GEDCOM; worried about who can see what, read about privacy.

Questions

Does Folkbranch run on Windows?

On Windows, Docker is the proven way. A PowerShell installer, install.ps1, is built and started on a Windows build server with every release, but nobody has tried it on a real Windows computer yet. The one-line install is tested on Mac and Linux.

Do I need a server?

No. On your own computer it runs with one command and you open it in the browser. A server is only needed if relatives should reach the archive from anywhere. Without one, ./folkbranch share gives the app a temporary address on the internet.

How much memory does it need?

It runs in about 70 MB of memory, and stays near 130 MB with a family of a thousand and twenty people looking. A Linux server with 512 MB of memory is enough.

How do I update Folkbranch?

Run the install command again. Settings and data are kept, and the database migrates on start. Take a backup first.
