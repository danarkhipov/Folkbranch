Free and open source (AGPL-3.0). Runs on your computer or server.

Install it with one command

One person in the family installs it. Relatives only open a link in a browser.

Paste this in a terminal. No Docker and no Node needed. On a Mac or Linux computer it takes under a minute.

curl -fsSL https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.sh | sh

Docker Desktop is the way that has been tried on Windows. Copy docker-compose.yml and .env.example from the repository, copy .env.example to .env, set BETTER_AUTH_URL and BETTER_AUTH_SECRET in it, then run this in that folder:

docker compose up -d

There is also a PowerShell installer, install.ps1. It is built and started on a Windows build server with every release, but nobody has tried it on a real Windows computer yet.

On a Linux server with systemd and 512 MB of memory. It starts with the server and sets up HTTPS by itself, with no Docker and no domain needed:

curl -fsSL https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.sh | sudo sh -s -- --server

With your own domain: point its DNS at the server and add --domain.

curl -fsSL https://raw.githubusercontent.com/danarkhipov/folkbranch/main/install.sh | sudo sh -s -- --server --domain family.example.com

If you already have Node. It runs the same installer; run it again to open the app.

npx folkbranch

After the command

  • It prints a link. Open it, name your family, and load the invented demo family to look around.
  • At home the app listens on this computer only. For relatives to open links, use a server, or run ./folkbranch share for a temporary address.
  • To update, run the same command again. Settings and data stay.

How it works

  1. 1

    Send a question by link

    Open a person, pick up to five questions or write your own, and copy the link. Send it in any messenger.

  2. 2

    The relative records on their phone

    They tap the link, pick a question and press one big button. No app and no account.

  3. 3

    You check it

    The recording waits in Review. Listen to it, then accept or reject it.

  4. 4

    It lands on the person’s page

    An accepted story sits on that person’s Stories tab, with their biography and photos.

For people who run it themselves

Small, one database file
SQLite and a folder of photos. About 70 MB of memory in our own test, about 130 MB with a family of a thousand people looking; a 512 MB server is enough.
Builds, automatic HTTPS
Ready builds for macOS and Linux on arm64 and x64; the Docker image is for amd64 and arm64. On a server, Caddy gets and renews a Let’s Encrypt certificate by itself.
Updates and backups
The same command updates it, with a database copy first. The server also copies the database daily; you can download a full copy any time.
GEDCOM
Import and export GEDCOM 5.5.1 and 7.0. Gramps files, Excel and CSV come in too.
MCP for AI agents
Connect Claude Code or Codex with a key. An agent’s edits wait for your approval.
Optional AI assistant
Off until you add your own key. What it reads goes to the provider you pick, or stays home with a local model.
AGPL-3.0, no telemetry
If the project stops, your copy keeps working. The only call the server makes by itself asks GitHub for a newer release; you can switch it off.

Honest limits

  • One author, and a young project. Expect rough edges.
  • Windows goes through Docker. The PowerShell installer has not been tried on a real Windows computer.
  • Of 10 app languages, 6 (Portuguese, French, German, Italian, Ukrainian, Polish) are machine translations marked beta.
  • There is no hosted version: you run it yourself.
  • No record collections, no DNA, and one family tree per install.

Questions

Is it really free?

Yes. It is open source under the AGPL-3.0 licence, with no paid plan. You pay only for your own server, if you use one. The optional assistant and cloud speech use your own keys, paid to their providers.

Do I need a server?

No. On your own computer it runs with one command and you open it in the browser. A server is needed only if relatives should reach it from anywhere; at home, a link opens only at home unless you run ./folkbranch share for a temporary address.

What does a relative see?

A link, a question and one big Start recording button. They need no account and no app, and the recording waits for your review before it joins the archive.

Does anything leave my server?

Not by itself. The one call the server makes on its own asks GitHub whether a newer release exists, with nothing about your archive, and you can switch it off. If you connect an AI provider or cloud speech, what the assistant reads and each recording go to that service, and the app says so first.

Can I bring my tree from Ancestry, MyHeritage or Gramps?

Yes, if the service exports GEDCOM. Folkbranch shows what the file holds before anything changes. GEDCOM has no photos themselves: drop the pictures together with the file and they attach to the right people.

How do backups and updates work?

The server copies the database every day, keeps the last seven, and copies it again before an update. They sit on the same disk, so also download a full copy under Settings and keep it elsewhere. To update, run the install command again.
