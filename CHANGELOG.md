# Changelog

Follows [Semantic Versioning](https://semver.org). Each version is a tag; ready images are at `ghcr.io/danarkhipov/folkbranch`.

## 1.0.0

First public release.

- A first-run guide that says what is set up and what is missing, with logos for the services it connects to.
- Install in one command from a ready image, and `./family connect` to connect Claude Code or Codex over MCP.
- A skill any agent can follow to install the app on a computer or a server.

## 0.9.0

- Merge two cards of one person: every value survives as a version, and one undo restores both.
- The person's card holds up under long names, huge families and no data at all.
- A copy of the database before every migration.

## 0.8.0

- Stories with a voice recorded in the browser or from a file, kept apart from facts.
- Readers suggest corrections for review; a link lets anyone view the family without an account.

## 0.7.0

- Print to PDF on one sheet or glued from several.
- Ancestors, descendants, closest family, folded branches, saved views, cards placed by hand.

## 0.6.0

- Download the whole archive as one checked file and restore it on a clean install.
- A list of what is left to check, and people marked on photos without a card.

## 0.5.0

- Several people and agents can work at once without losing each other's edits.
- A chart layout that crosses fewer lines, drawing only what is in view, one readable type scale.

## 0.4.0

- A built-in AI assistant on your own key, from several providers, with the same permissions as a person.
- Protection against prompt injection, and a checked tool for every action.

## 0.3.0

- One-command install with Docker and automatic HTTPS, a protected first setup, expiring tokens.

## 0.2.0

- Versions of a date, place or name, each with its source and status.
- Structured sources; import from Excel, CSV, JSON and plain text.

## 0.1.0

- The family chart and a page with photos for every relative.
- GEDCOM, MCP and tokens with changes reviewed by a person, full history with undo.
